⏱ Stylish Stopwatch Web App
A modern, responsive stopwatch web application built with HTML, CSS, and JavaScript. This project includes core stopwatch features such as Start, Pause, Reset, and Lap tracking, along with millisecond precision (accurate to 1/100th of a second). The UI is clean, interactive, and optimized for both desktop and mobile devices.

🚀 Features
Real-time time tracking in HH:MM:SS.ms format

Start, pause, and reset stopwatch functionality

Record lap times with one click

Beautiful, responsive design with soft shadows and gradients

Built with plain HTML, CSS, and vanilla JavaScript (no libraries)

📁 Technologies Used
HTML5 for structure

CSS3 for styling and layout

JavaScript (ES6) for functionality and time logic
